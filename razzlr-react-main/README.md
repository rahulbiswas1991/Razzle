
# Razzlr Frontend

This is a React project using Vite, Tailwind CSS 4+.

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```

3. Configure your API base URL in a `.env` file at the project root, example env file is provided.

## Project Structure
- `src/pages` - Login and Dashboard pages
- `src/store` - Redux store and slices
- `src/services` - API and auth services
- `src/utils` - Utility functions (cookies, Facebook SDK)
- `src/components` - Shared components
